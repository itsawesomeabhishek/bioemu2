# Contributing to BioEmu2

We welcome contributions and suggestions. Open a pull request to propose a
change.

Most contributions require agreement to a
[Contributor License Agreement (CLA)](https://cla.opensource.microsoft.com),
confirming that you have the right to grant Microsoft permission to use your
contribution. When you open a pull request, the CLA bot will indicate whether
you need to sign and provide instructions. You only need to sign once for
repositories using the Microsoft CLA.
